ℹ️ About This Dashboard

Built during the KIRO Data Engineering Workshop. Powered by DuckDB-WASM running SQL queries directly in the browser against a pre-cleaned Parquet dataset.

Dataset: BIR PSCG Annual Collections CY 2005–2024
Records: 2,480 (17 regions × 101 provinces × 20 years)
Pipeline: Node.js + DuckDB → Parquet → DuckDB-WASM
Charts: Chart.js v4 with animated transitions
